# 中英界面与生成语言合同

2026-09-11：本轮确认并实现的语言边界。README、旧设计稿与本页冲突时，以本页及实际实现为准。

## 产品规则

- 应用只有一份工作区与内容数据；界面可在简体中文（zh-CN）和 English（en）之间切换。
- 应用全局语言保存在配置目录的 ui-locale.json。首次没有偏好时显示语言选择；选择不依赖工作区。
- 历史成果、历史讨论、原文与用户自定义内容不因切换而翻译、改写或重新生成。
- 新提问、新任务、重新生成按提交时的语言生成。请求语言优先于历史成果语言、问题语言和自定义提示词中的语言要求；自定义提示词原文仍保留，约束只用于运行时请求。
- 已入队或正在执行的任务继续使用提交时冻结的语言。多阶段生成、修复、续跑均读取同一快照。语言切换不取消任务。
- 导出的标题、章节名称和字段标签使用导出时的界面语言；成果正文、术语及用户文本保持原样。批量导出的语言在计划中冻结。

## 实现入口

| 内容 | 入口与约束 |
| --- | --- |
| 界面词库 | src/i18n/messages。固定文字使用 t；旧辅助模块的应用自有标签可使用 uiText。不得对用户正文或组装后的导出全文做替换翻译。 |
| 启动与切换 | App、LanguageGate、LanguageChangeConfirmModal、LocaleContext、src-tauri/src/ui_locale.rs。只更新语言偏好与界面状态。 |
| 提示词设置 | SettingsWorkbench 在语言变化时重读词库，忽略过期响应；读取和保存显式指定语言。草稿按语言、文档种类和槽位隔离，保存成功才清除对应草稿。 |
| 提示词协议 | PromptSettingsProjection 增加 locale；保存/恢复请求增加可选 locale，旧调用方仍兼容。存储中的原始自定义稿不修改。 |
| 地图 | outline_plan 把 outputLanguage 纳入计划与摘要；生成、检查、修复、局部展开读取冻结值。待确认计划过期时重新预览，已入队任务保留原快照。 |
| 旁批 | guide_plan、guide_runtime、guide_pipeline、guide_generation 和 guide_module 从计划到发布一致传递语言，包含试写、备忘、修复与补充。 |
| 讨论与 Lens 追问 | 普通讨论与压缩提示词在提交时一起冻结；Lens 追问显式传 outputLanguage。引用的旧 Lens 与已有讨论正文保留原文。 |
| 内置人物 | 中英预设保存在 prompts/guide-characters 及其 en 子目录。只转换与出厂值相同的字段；用户修改的字段保留。设置保存时将未编辑的显示翻译还原为原始字段；新生成冻结本次语言的角色快照。 |
| 智能集合 | 按内置标识显示翻译，自定义集合名保持原样。 |
| 元数据摘要 | 语言代码统一识别 en、English、英文、英语及 zh-CN、Chinese、中文等旧值；无明确偏好时按界面语言选择，手动钉住的摘要优先。摘要正文不翻译。 |
| 导出 | export_module 在写入固定标签时选语言，不处理已组装正文。BatchCommand/ExportItemPlan 的 locale 对旧数据默认 zh-CN。 |
| 错误 | 界面使用可翻译的恢复提示，结构化错误码不变；服务商和系统的原始技术信息在诊断详情中按原文保留，展示前脱敏，不自动写入文件。 |

## 兼容要求

工作区数据库和提示词原文不因切换迁移或清空。旧任务缺少语言字段时沿用其历史默认，不能读取执行时的新界面语言。已生成图、旁批和用户文本不进行批量翻译。计划与生成快照中的语言属于任务输入，不能在恢复时重新解析当前偏好。

字体预览中的中英文示例、专有名词、模型 ID、代码/公式、来源原文和原始诊断信息允许保留原来的语言。它们不能作为普通界面漏译的豁免。
