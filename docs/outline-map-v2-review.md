# 大纲与脉络图谱 V2 审查与修复报告

日期：2026-09-11。
范围：[执行计划](outline-map-v2-plan.md)对应的地图功能、提示词、迁移、生成与界面。
基线：HEAD 为 c4159926ebd763a1a983957792be5c41de2f4f80；本功能由未提交修改和新增文件组成，没有独立实现提交。审查保留了其他功能的既有修改。
结论：本轮发现的问题已修复，代码及自动化回归通过。真实模型内容与桌面视觉验收仍待完成。

## Standards：规范与数据保护

### S1：旧数据库升级会删除地图及恢复材料——已修复

原 migrate_outline_epoch 在 epoch 小于 3 时删除总图、局部图、计划、任务并重置阅读状态，违背计划 §10.1 的无损迁移要求。

现在只在事务中更新兼容标记。测试逐行验证旧地图、局部图、计划、任务、checkpoint、attempt、usage 和阅读状态保留，以及重复打开、失败回滚和重试。数据库全局 schema 号和 OUTLINE_EPOCH 均未上调。

### S2：提示词迁移及恢复会丢自定义历史——已修复

旧擦槽逻辑先于新迁移备份执行；整套升级会覆盖已有 previous；重复恢复默认也可能抹掉可恢复稿。

现在 current／previous 都保存协议来源，按论文／教材独立迁移；旧自定义稿仍走 v3，混合协议在生成前阻止，未知未来协议明确提示。整套新版默认通过一次读写完成，设置页、Tauri 命令和内存适配器已接通。重复恢复默认保留已有历史。

### S3：地图删除入口可能跨工作区取模块——已修复

删除操作改为捕获一次 WorkspaceRuntime，使用同一运行时的任务与地图模块，并和开始操作共用互斥入口。总图／局部图删除同时使相应旧计划失效；保留发布完成标记，避免旧任务恢复后重新发布已删除内容。

启发式优化：统一生成阶段执行逻辑、复用提示词比较用的归一化函数；保持旧版任务和其他阅读功能的运行路径。

## Spec：计划符合性

### F1：解析失败没有修复，修复后的任务不能正确恢复——已修复

- 格式解析和定位校验失败均进入共享的修复流程。
- 修复输入保留原始响应，包括无法解析的 JSON。
- 总图仍只有一次共享额外修复额度；局部图最多一次。
- 恢复按逻辑调用槽重放已收到的修复结果，不把重放误判为再次消耗额度。
- 已提交但结果未知的调用不自动补发。

### F2：付费响应、取消和收据恢复不完整——已修复

- 地图专用适配器先保留已返回的响应，再处理取消。
- 每个阶段调用前和发布前均检查取消与冻结依赖。
- 收据按任务、逻辑槽和精确 route 去重；恢复补录已保存响应的收据。
- 复核失败保留可核对的候选，不移动正式 head。
- 已完成任务再次进入恢复路径保持幂等。

### F3：计划与实际执行材料没有完整绑定——已修复

- 冻结 PDF 摘要、OCR、完整定位目录、页数、窗口、提示词、route／model 与期望版本。
- 开始时核对文档与 planId／planDigest，避免使用其他文档的计划。
- 增加 plan_outline_deep_dive 接口与真实确认流程；局部图冻结父修订、目标及当前局部版本。
- 局部版本变化在付费前阻止，不等到发布才发现。
- 同一计划已有任务时返回原任务，避免失败后重新入队丢失原 checkpoint。
- 开始与删除入口有文档范围的互斥检查。

### F4：窗口预算和来源缓存恢复可能产生额外调用——已修复

- 每次发送前检查实际系统稿、PDF 估计、目录、候选／修复材料、schema 和输出预留。
- 超预算保留已收到成果并明确停止，不截断原文或候选图。
- 精确查询 PDF-only 来源根，单列 rootCalls。
- 局部确认显示冻结的 rootCalls，不重新查询后悄悄改变额度。
- 来源根的实际发送点也检查额度并保存使用标记，封住缓存查询与发送之间的竞态。
- 缓存失效不会在生成内部悄悄重建来源根并重复请求。

### F5：正式发布和候选状态不完整——已修复

- 总图／局部图发布在事务中核对来源、任务状态和期望版本。
- publishId 的完成标记保存在计划记录中，替换或删除旧 revision 后仍有效。
- 事务失败后可重放已收到结果，且不重复计费。
- 候选记录按 publishId 幂等保存并提供 latestAttempt 投影。
- 成功生成新的正式图后，早于它的失败候选不再显示为最新尝试。
- 投影区分未复核候选、已复核、带缺口定稿和局部自检。

### F6：自由图协议和引用错误会被静默吞掉——已修复

- 空关系 ID、无效分组、无效缺口引用和越界建议页都会明确报错。
- 模型输出未知字段拒绝；持久化读取不再归一化或改写 ID。
- groups／gaps 与协议约定一致地可选。
- 自由角色、自由关系、单节点、零边、多分量、回路、无向关系、自环和平行关系继续合法。
- 未知／非字符串协议不能猜作旧版；v40 等标识不会误判为 v4。

### F7：关系阅读、局部计划与状态界面存在断点——已修复

- 节点选中后可以切换到关系详情；重置布局不会丢失关系回调。
- 平行、反向和自环关系使用独立路径，保留方向及可选择性。
- 关系详情、列表降级、引用跳转和键盘操作已补齐。
- v4 局部图按真实协议显示为局部自检。
- 文档／父图／节点切换后，旧异步响应不能覆盖当前状态。
- 未完成候选保留时仍可重新计划；父图换版后退出失效局部视图。
- 局部图不提供第三层生成入口。

### F8：独立提示词和地图导出缺少完整信息——已修复

- 六份中文稿保留原有全文，补齐各自独立可见的 graph、节点、关系、引用、分组和缺口字段说明。
- 不再依赖“与构图相同”来假定独立阶段看过另一份提示词。
- 补齐材料边界、修复输入、物理页码与 JSON／LaTeX 转义规则。
- 运行时稿与 docs/note/outline-prompts.md 逐字同步。
- Markdown 导出改用可读节点标题表达关系，保留方向、理由、引用用途、不确定性、分组与缺口。
