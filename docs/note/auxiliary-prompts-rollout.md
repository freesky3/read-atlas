# 辅助阅读成果生产同步方案

状态：已确认并实施；离线验收通过（2026-09-08）。

依据：[完整提示词与应用规则](auxiliary-prompts.md)。文档根、符号表、术语表、元数据的提示词讨论稿，以及文库展示与兼容规则已确认；本文件安排实施依赖和验收，不替代或改写已确认正文。以下保留已确认的实施依赖；当前实现、兼容规则与验证范围见 [辅助成果生成](../auxiliary-generation.md)。本次复用 schema 8 的 JSON 与成果版本存储，不需要新增 DDL 迁移。

## 范围与现状

本轮同步文档根、术语表、符号表和元数据。已经恢复完整原稿的论文 Brief 作为回归保障；教材 Brief 和其他尚未逐项讨论的功能继续保留各自现状，不把本轮同步算作其提示词已经优化完成。

现有独立生成流程已经具备分项调用、共享 PDF 来源根、响应检查点、用量记录和分项发布。新方案在这些基础上推进，保留已有队列和成果读取能力。

实施前核对的具体差距（以下为原计划记录，均已完成本轮对应改造）：

- 术语表运行时仍是 term、definition、aliases 三字段，需升级为 term、aliases、definition、usage、sources 五字段。
- 符号表运行时仍是 symbol、meaning、scope 三字段，需加入 sources，并允许同形异义条目分别存在和操作。
- 元数据运行时仍是论文、教材两种平铺结构，需升级为同一套 document、container、relatedVersions、sources、issues。
- 当前本地校验器只覆盖现有有限 Schema 词汇，尚不能完整校验新结构的可空对象、可空字符串、枚举、数值边界及跨字段约束。
- 术语和符号仍按 term 或 symbol 合并；局部上下文匹配只匹配主名称，未使用术语 aliases，也没有按已确认语义处理同名异义。
- 元数据锁定值先合入新生成结果，再将整个结果以 model 来源同步，无法准确区分原始提取值与人工值。
- 入队任务已有提示词快照，但执行和重试仍根据当前代码选择 response_schema；新旧 Schema 不能只原地替换。
- PDF 根缓存按 revision、route、model 等隔离，当前键尚未包含实际根提示词的指纹。更换根提示词时需同步缓存识别。
- 文库年份和章节排序仍读取旧字段；成果发布与元数据展示同步分步执行，需要解决中途失败及迟到任务覆盖的问题。

## 实施顺序

### 1. 固化完整提示词与生效片段清单

将确认正文完整组装到 paper-root.md、glossary.md、symbol-table.md、metadata.md，并同步提示词手册及论文、教材槽位引用。

组装依据应是明确的生效片段清单，排除历史对照段、被替换段、实施待办和应用规则。不能把讨论文档中每个代码块无差别拼接，也不能只保留字段清单而删掉解释与边界规则。

保留原讨论记录，建立逐段正文保真检查；格式变化只允许约定的标题、列表和换行处理。论文 Brief 的原稿保真检查继续保留，避免本轮同步回退已有九字段正文。

完成标准：可审阅的四份完整运行时提示词与来源对应清单，文本核对通过，但尚不单独启用新输出结构。

### 2. 建立带版本的结构契约与校验

文档根协议、成果输出协议和应用保存格式分别版本化。新术语表、符号表和元数据使用明确的新协议标识；保留旧独立成果 v1 与旧四合一任务的处理分支。

每个协议版本具有明确的 Schema 与解析规则。Provider 请求和本地验证使用同一权威契约；如果需要适配 Provider 支持的 Schema 表达，应保留本地完整约束，不能静默忽略未实现的校验关键字。

本地检查分为结构和关联两部分：

- 精确字段、嵌套对象、枚举、可空类型、非空字符串、数组元素、数值范围及规定的数组唯一性。
- PDF 页序、JSON Pointer 是否指向实际位置、问题及候选的影响范围、所属出版物关系、摘要完整程度与 textGap 锚点。
- 候选路径范围按解码后的路径层级判断，不做会误认相似字段名的字符串前缀比较。
- 标识符格式整理不自动代表校验成功；原文疑似错误仍按已确认规则保留，不由结构校验擅自修正。

完成标准：新旧合法响应分别通过各自协议，不合法响应给出具体位置与原因；技术校验不声称已经证明每项书目判断符合 PDF。

### 3. 保存原始成果、人工设置和稳定条目身份

复用现有成果版本与当前版本机制，增加保存人工修改、选择、清空、隐藏及来源关系所需的数据。迁移使用项目届时适用的后续版本，不重写已执行的数据库迁移。

原始模型提取版本保留不变，人工设置与有效展示分别维护。模型生成的结构不加入应用 ID、锁定状态或处理状态。

为术语、符号、贡献者、版本、摘要及其他需要单独操作的条目建立应用维护的稳定身份。身份不等同于名称或数组下标；同名异义和共享别名允许同时存在。

新旧条目只有在对应关系可靠时才迁移人工设置。无法对应的人工内容仍保留并说明来源，不丢失、不自动贴到另一个同名条目。来源、问题及缺口锚点随可靠编辑更新，无法重建的关联明确失效，原始版本保留供核对。

旧平铺字段、旧成果内容和 _pinned 在迁移前完整保留。无法确定事件或归属的旧锁定值作为兼容覆盖值继续生效，不反向制造出版事件、作者角色或所属出版物。

完成标准：同名条目可独立编辑、钉住、删除；重新生成不会覆盖人工设置，也不会把人工值伪装成新模型原稿。

### 4. 接入冻结协议、缓存与一致发布

新任务入队时一起冻结实际提示词、根提示词、成果协议与 Schema 版本、模型和 Provider 路由；可选的 Brief 主题线索继续冻结其来源与内容。

旧任务使用原来匹配的冻结协议。已有 v1 响应检查点恢复时使用 v1 规则，不能被当前新 Schema 重新解释。协议变更不能让已经付费取得的响应失去可恢复性。

根缓存识别纳入实际冻结根提示词的版本或内容指纹，根查找、创建锁、失效处理及所有共享根调用端使用相同规则。不同根提示词不能误复用；仅修改下游成果提示词不必因此重复建立相同 PDF 根。

继续保持 PDF 来源根不含 Brief 或其他成果，术语表默认独立读 PDF，符号表与元数据不携带 Brief。带 Brief 线索的术语任务仍只取已确认的有限主题字段。

保留原始响应、检查点和用量记录。源不可读、响应截断、Schema 或关联校验失败时不发布为可用成果，不用空内容覆盖当前版本。恢复本地步骤不重复付费调用；重新请求模型应是明确的新生成行为并留下调用记录。

原始成果、有效展示数据和当前版本切换应具有一致的提交边界。重试不重复产生同一任务的成果版本；迟到的旧任务不能把较新的当前成果或展示结果覆盖回去。失败时保留上一份可用结果。

完成标准：缓存隔离正确、旧队列可恢复、失败不产生半更新状态、调用和发布均可追溯。

### 5. 更新界面、展示和排序

术语表展示 definition、usage、aliases 和出处；符号表展示含义、范围和出处。未知页序保留文字线索，只有可靠 PDF 页序才提供对应跳转；正常空值不一律显示为错误。

元数据先展示便于识别的标题、角色署名、带事件说明的年份和所属出版物，再按需展开版本、出版主体、完整日期、标识符、摘要、出处和问题。应用界面不直接暴露用于内部定位的 JSON Pointer、协议代次或数据库实现细节。

实现已确认的人工值优先级、旧记录标识、冲突处理、年份事件选择、摘要语言选择和 textGap 显示。原文值与人工值的来源及核验状态分别呈现。

年份、章节、标题等展示与筛选排序共用应用规则，数据库查询、桌面界面及内存适配器保持一致。未知年份与不可解析章节号在双向排序中均放在可排序项之后；保留原始编号，不为排序猜改。

完成标准：用户能够阅读、比较、修改与锁定新结构；旧记录可继续查看；展示与排序反映同一份有效信息。

### 6. 同步下游读取与提示词设置迁移

检查翻译、讨论和其他实际读取术语表、符号表或文库投影的功能。术语匹配使用主名称及已确认别名，共享别名不强行合并；符号匹配保留不同含义与范围，不能固定取第一个同名条目。

按当前阅读位置选择必要内容，保留判断所需的语义与范围。新增来源、版本或问题结构不能被无差别塞入每次阅读调用，导致文档根或局部任务混入无关成果。

旧格式读取采用明确的兼容适配；不能猜造旧条目的 usage、sources 或核验状态。模型输出格式、应用存储格式与下游阅读输入各自有清楚的转换边界。

新默认提示词按保存代次及已知默认内容识别和升级。用户自定义稿完整保留，并绑定其实际支持的协议；旧稿不能直接配新 Schema。设置页明确当前使用的版本，并允许切换已定稿版本或恢复兼容的旧自定义稿，不静默覆盖自定义内容。

完成标准：下游功能不因新字段而丢失信息或误并同名含义，旧自定义稿与新默认稿都不会被错误配上不匹配的解析协议。

### 7. 完成迁移验收后统一启用

允许按前述顺序分阶段开发与验证；新协议的默认启用应在读取、编辑、保存、校验和迁移链路完整后进行，不让新提示词先向只能处理旧格式的界面发布结果。

启用前保留所需的数据与设置备份，迁移可重复执行而不重复创建覆盖记录。保留旧协议读取和必要的功能回退路径，回退时不删除已经生成的新原稿或人工记录；不能假定任意旧程序都能直接读取迁移后的数据库。

同步 README、提示词手册、数据协议、上下文说明和决策记录，并明确生产支持范围及真实验证程度。既有无关改动保持原样。

## 验收场景

| 场景 | 应验证的行为 |
|---|---|
| 预印本同时列正式发表版信息 | 当前版本和关联版本的 DOI、刊载位置、日期分别保存，展示不会混成同一版本 |
| 单章、整书与节选 | 文档层级、收录范围、作者与编者、整书年份、章节编号各归其位 |
| 同名术语、共享缩写、同形符号 | 多个含义独立存在；编辑、钉住、删除和重新生成不互相覆盖 |
| 原文保真 | 完整提示词正文保留；公式、反斜杠、原文名称、JSON 换行与列表正确处理 |
| 多语言与结构化摘要 | 选择一份摘要，保留原文小标题和顺序；不混合不同条目 |
| 跨页、缺损及不可辨认内容 | PDF 页序与印刷页码区分；textGap 与 partial 一致；未知位置不编造跳转 |
| 多个日期、候选与规范化限制 | 年份不任取，原文值不因规范化失败而丢失，候选不混入确定值 |
| 路径与下标错误 | null 子路径、越界、错误路径范围及摘要锚点被具体指出，不发布为有效成果 |
| 旧字段、旧成果与人工锁定 | 旧记录可查看；明确清空不被填回；人工值和旧来源不冒充本次模型提取 |
| 新旧队列、重试与迟到结果 | 按冻结协议恢复；本地重试不重复付费；迟到任务不覆盖较新当前结果 |
| 中途失败与一致发布 | 任一保存步骤失败时，不出现成果已切换而文库仍停留旧投影的半更新状态 |
| 根缓存与独立上下文 | 根提示词变化正确隔离；相同根继续复用；兄弟成果不进入 PDF 根历史 |
| 显示与双向排序 | 年份事件、章节 1.2 / 1.10 与未知项位置在各适配器中一致 |
| 自定义稿及重复迁移 | 默认升级与自定义保留可区分，协议正确绑定，重复迁移不丢失历史或重复覆盖 |

验收使用能观察行为差异的离线集成用例，覆盖 Schema、持久化、异步恢复、界面操作和排序；已有适用测试继续作为回归检查，不编写仅复述实现的测试。

真实模型质量评测另用有人工对照的论文、整书、单章、双语摘要和缺损 PDF 样本，记录模型、提示词版本、提取错误与调用费用。离线 mock、编译成功或路径校验通过，均不能替代对真实提取质量的评价。本轮未进行真实模型调用。
