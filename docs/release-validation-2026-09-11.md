## 安全升级

- PDF.js：5.7.284 → 6.2.108，处理 GHSA-hq66-cqwq-w95j；同步改用加载参数对象和 loading task 生命周期清理。
- Vitest：3.2.7 → 4.1.11，处理 GHSA-82fw-gwwq-j7x9。
- h2：0.4.15 → 0.4.16，处理 RUSTSEC-2026-0258。
- chacha20：0.10.1 → 0.10.2，离开已被撤回的版本。

Gitleaks 的唯一例外是 provider_routing.rs 中 mistral-key-a / mistral-ocr-2407 的固定单元测试调用，已核对为虚构输入。规则只允许完整匹配该行，不忽略整个测试目录，也不隐藏真实密钥。

## 保留的依赖警告

- 5 个 unic 0.9.0 包被标记为 unmaintained，经 urlpattern → tauri-utils 引入 Windows 依赖图。等待上游兼容升级，不私自换掉核心解析依赖。
- proc-macro-error 1.0.4 的 unmaintained 和 glib 0.18.5 的 unsound 公告存在于跨平台锁文件中，不在本次 Windows 依赖图里。Linux 不列为已支持平台。
- 这些条目没有加入 cargo-audit 忽略列表。下次 Tauri 依赖更新时以及稳定版发布前重新评估，最迟 2026-10-11 复核。

Rust release 构建保留 55 条现有警告；本轮没有为消除警告而删除持有锁的资源或重排整个后端。
