# Read Atlas 0.1.1：Windows 安装生命周期验收

日期：2026-09-11。发布目标：Windows x64 Alpha，按用户安装的 NSIS 包。环境：Windows 11 Home 10.0.26200、普通用户权限、已安装 WebView2。

## 验证范围

使用与公开下载字节完全一致的最终 NSIS 安装包，安装到专用测试目录。测试进程使用独立 WebView2 用户目录，因此没有加载日常文库。系统凭据未修改，原有全局配置文件的校验值在验证前后保持一致。

升级基线为内部 0.1.0 包：使用此前已构建的应用二进制，按 Read Atlas 的安装身份重新打包。它没有公开发布。此次验证覆盖同一安装身份下的版本替换，不将其描述为所有旧开发版本的迁移保证。

## 验收发现并修复的问题

1. **无 Brief 时手动标签不显示**：数据库标签未丢失；卡片转换却读取了生成关键词。现使用持久 tags，并覆盖删除标签后不应从旧关键词复活的情况。两条最小测试先失败后通过，文库相关 81 项测试通过。
2. **正式包无法加载本地 PDF**：显式 connect-src 缺少 Windows 资产域和 Tauri IPC 协议，正式安装版出现 Failed to fetch。已仅补充本地协议／域，保留动态文库文件范围和外部站点限制；实际最终安装包渲染和 CSP 事件复测通过。

## 仍未覆盖的环境

这不是全新 Windows 虚拟机验收，也未测试缺少 WebView2 时的自动下载、管理员级 MSI、代码签名、全部历史版本、网络盘、性能 P95 或全部真实模型服务商。Alpha 的支持范围与已知限制应随 Release 保留。
