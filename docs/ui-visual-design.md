## 2. Liquid Glass 设计系统 Token

### 2.1 配色与材质

- **Light 主题 (`liquid-light`)**：
  - 背景：冷色学术淡灰渐变（`#eaedf2` → `#dde2e8`）。
  - 玻璃层：`rgba(255, 255, 255, 0.62)` + `backdrop-filter: blur(28px) saturate(190%)`。
  - 六重立体焦散折射阴影（`--liquid-glass-shadow`）：双向对角棱镜高光（`inset 2px -2px`、`inset -2px 2px`）、内部二级折射光晕（`inset ±6px ∓6px`）、暗色轮廓 meniscus 分离圈（`inset 0 0 2px`）与柔和空间投影（`0 8px 24px -4px`）。
  - 45° 对角镜面高光光斑（`--liquid-glass-sheen`）与悬浮深度投影（`--liquid-content-drop-shadow`）。
  - 文字/主色：深石板青黑 `#0f172a`、次要信息 `#64748b`、科技主蓝 `#2563eb`、学术绿 `#16a34a`。
- **Dark 主题 (`liquid-dark`)**：
  - 背景：黑曜石深邃渐变（`#0b0f19` → `#030712`）。
  - 玻璃层：`rgba(18, 25, 40, 0.68)` + `backdrop-filter: blur(28px) saturate(190%)`。
  - 镜面高光与暗夜六重焦散：`inset 2px -2px` 白色微棱、`rgba(56, 189, 248, 0.22)` 科技蓝折射光晕与 `0 8px 24px rgba(0, 0, 0, 0.45)` 空间深度。
- **Warm 主题 (`warm-editorial` / Claude Editorial)**：
  - 核心设计哲学：温暖人文、克制优雅与平静沉浸的阅读思考氛围，彻底去“廉价科技 AI 味”与冰冷蓝紫调。
  - 背景与纸张：象牙暖白纸张基底（`#faf8f4` → `#f4f0e8`），纯白/暖白固体层叠纸张卡片（`#ffffff`），极细 `#e8e2d8` 轮廓线与超柔纸面微投影（`0 1px 3px rgba(38, 28, 20, 0.04)`）。
  - 核心色彩系统：Anthropic 标志性**赤陶色（Claude Terracotta `#c15f3e`）**作为主按键、重点指示器与用户提问气泡底色；辅以鼠尾草绿（Sage Green `#3d6d45`）与灰岩蓝（Slate Blue `#385d7f`）等 Claude Cookbook 式莫兰迪标签色。
  - 对话流呈现：用户提问采用 Claude 移动端经典**赤陶色气泡（#c15f3e + 白字）**，助手回答为纯净无框纸面排版。
  - 字体系统：标题与品牌名采用文人气质的优雅衬线体（`Instrument Serif` / `Newsreader` / `Georgia`），正文保持高易读性的现代无衬线体。
  - 材质处理：禁用高光光斑与折射玻璃（`backdrop-filter: none`，`::after` 光斑隐藏），还原纯粹纸质触感。

### 2.2 排版与字体

- 浅色/深色主题：`-apple-system, BlinkMacSystemFont, "Inter", "Segoe UI", Roboto, sans-serif`。
- Claude 暖色主题：标题采用 `--app-font-serif`（`"Instrument Serif", "Newsreader", "Tiempos Headline", "Georgia", serif`），正文使用高质量现代无衬线。
- 代码/元数据：`"DM Mono", Consolas, monospace`。
- 讨论与阅读成果正文共用 `--discussion-font-size`（14 / 15 / 17），`A−`/`A+` 写在讨论顶栏和成果索引；变量必须设在 `.workspace-grid` 上。PDF zoom 与此无关。

## 3. 核心交互规范

### 3.1 对话气泡（Discussion Bubble Topology）
- **用户问题**：
  - 必须**框起来**：使用 Liquid Glass 磨砂圆角卡片（`border-radius: 18px 18px 4px 18px`）。
  - 必须**靠右显示**：`align-self: flex-end; margin-left: auto; max-width: 85%`。
  - 用户头像与时间戳排布在气泡右上角。
- **AI 深度回答**：
  - 必须**全宽无框（Frameless Editorial）**：去除对话气泡边框与背景色限制，最大化利用 40% 宽度阅读长篇论文解析。
  - LaTeX 块级公式居中渲染，代码块内置复制操作与深色主题适配。

### 3.2 学术级 OCR 选区与持久化绿勾
- **选区渲染**：
  - 采用 **4px 圆角实线边框**（Solid line with 4px border radius）。
  - 普通/悬停态：浅薄荷绿（`rgba(34, 197, 94, 0.09)` 背景，`rgba(34, 197, 94, 0.5)` 实线边框）。悬停只预览，不出现工具条。
  - 单击选中后浅绿保持，工具条钉住；引用/聚焦态：高亮翡翠绿（`rgba(22, 163, 74, 0.16)` 背景，`#16a34a` 1.5px 实线边框 + 微光晕投影）。
- **持久化绿勾（✓）**：
  - OCR 微操作胶囊只在 **选中** 时显示（不要靠 `:hover`，否则鼠标移向胶囊会掉 hover）。若对应 Block 本地已生成 Lens / Translation 成果，按钮后自动打上绿色勾号徽标。
- **气泡动作**：助手只留分叉 / 循环图标（分支、重生成）；用户只留笔形（编辑为新分支）。正文色、高对比，tooltip 写全名。不要「Set current branch」文字按钮。
- **公式**：`.latex-hit` 悬停浅绿；单击复制 `$...$` / `$$...$$`。

### 3.3 分割线与独立视口滚动
- **分栏分割线（Workspace Splitter）**：
  - 宽 8px，居中带有显式磨砂抓手药丸（`width: 4px; height: 48px; border-radius: 9999px`）。
  - 鼠标悬停/拖拽时动态点亮科技蓝并扩展至 72px。
- **视口滚动锁定**：
  - 窗口主体采用 `100vh / max-height: 100vh / overflow: hidden` 绝对锁定。
  - PDF 画布与 Chat 消息流分别拥有独立的内部滚动容器，互不干扰。
