## 独立上下文与契约

- 仍由四次独立调用生成 Brief、术语、符号和元数据；每项有自己的版本、失败状态和重试。符号与元数据不接收 Brief；术语只有显式选择时才接收冻结的四项主题线索。
- PDF 来源根不含阅读成果或读者设置。根身份包含 PDF 修订、模型、精确 Provider route 和实际冻结根稿的 SHA-256。相同根稿继续复用；不同根稿分开缓存、加锁和失效。
- 新辅助任务冻结 v2 协议及完整 responseSchema；旧独立任务使用 v1，Brief 继续使用其九字段 v1 契约。Provider 请求与本地校验读取同一冻结 Schema；无快照的旧任务回落到保留的固定 v1 契约。
- v2 本地校验覆盖精确字段、可空类型、枚举、非空字符串、数组和整数约束、真实 PDF 页序上界、JSON Pointer、候选影响范围、container 关系以及摘要缺口。路径范围按解码后的层级比较，不能穿过 null 或访问越界下标。
- 术语与符号 sources.supports 是中文说明字符串；metadata 的 supports 是 fieldPath / explanation 数组。metadata 的路径根是 metadata 值本身，不能额外加 `/metadata`。
- 字段与定位校验只证明结构和内部关系满足合同，不证明提取的书目归属、原文转录或学术含义正确。

## 原稿、人工设置与发布

保存格式以 `_format: auxiliary-v2` 标识。`_model` 是不可变模型原稿；人工设置和有效内容另存。应用维护的 ID、锁定状态、展示选择或关联状态不进入模型输出 Schema。

术语和符号使用 `_id` 操作；同名异义和共享别名允许并存。修改、锁定和删除只影响所选条目。重新生成时，仅在原语义内容能唯一对应时迁移身份和设置；否则保留独立人工条目并提示尚未对应。隐藏记录与暂时缺失分开保存。历史 `_pinned` 和独立 override 表均可读取，不因名称相同而把一项旧覆盖贴到多个含义上。

元数据按字段保存人工覆盖，并为涉及数组的路径保存原条目锚点。数组重排后，只有原条目可唯一对应才迁移覆盖；无法对应的值保留为待核对内容。贡献者、版本、日期、摘要等的应用身份位于独立身份映射，不向模型添加 ID。明确清空、人工年份、所选日期、摘要语言偏好与指定摘要分别保存。

出处和问题仍可对照原稿阅读。可靠对应的目标可以在有效内容中定位；字段被改写或结构无法对应时，相关链接标记失效，缺口标记不再套到另一段文字上。人工值不会自动继承原稿证据的核验含义。

编辑发布新版本，历史 content_json 不原地改写。新版界面发送所见 artifact ID，过期编辑会拒绝，避免覆盖后台刚生成的版本。成果与文库投影在同一事务提交；失败保留上一个版本。同一任务重复恢复不重复发布；较早任务不能切回较新的成果。PDF 修订改变时，迟到结果只保存为历史；旧人工内容保留来源，不当作新 PDF 提取事实。

原始模型输出与恢复所需结果先写入检查点；校验失败也保留用量记录。重试本地解析或发布不会再次请求模型。旧四合一处理器继续处理历史任务，但不能覆盖已经独立生成的当前成果。恢复兼容 v1 元数据稿时，已有结构化原稿及人工设置继续保留，新 v1 提取单独标为兼容记录。

## 展示与下游读取

元数据先显示当前文档标题、作者、带依据的年份与所属出版物，再展开署名角色、版本、日期、标识符、出版主体、原文摘要、出处和问题。只把当前 document 的 author 角色列为作者；编辑、译者与所属对象保持各自身份。原文书目字段不会因界面使用中文而自动翻译。

展示年份优先使用 publication、print_publication、online_publication、release 的可靠规范化值。同一优先级出现不同年份时提示待核对，不任取较早或较晚值。单章或论文集文章没有自己的年份时，可以使用所属书籍或论文集年份并注明归属；版权、印次、投稿、收稿和录用时间不自动成为展示年份。人工选择可覆盖自动选择。`publicationYear` 不被复用成发布年或所属出版物年；卡片的 `displayMetadata` 保存有效年份及标签，显示与排序使用同一值。

年份与章节支持方向切换；未知年份及不可解析章节号两个方向均放在末尾。原章号保留，1.2 与 1.10 按分段整数比较。数据库查询和内存文库适配器保持相同规则，方向变化会改变分页指纹。

摘要按人工指定优先，否则按语言偏好、该语言内的完整程度及原文顺序选一份，不混合不同摘要。可靠摘要缺口显示位置标记；缺口位置不明时保留说明。指定摘要在新原稿中无法唯一对应时提示核对，不悄悄换成另一份。旧摘要不被自动标成完整。

翻译等局部任务用术语主名称和 aliases 匹配，保留所有命中的不同含义；传递 term、aliases、definition、usage 或 symbol、meaning、scope。整份出处、元数据版本和问题目录不会因此混入每次局部阅读输入。
