## Dependency notices

[THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt) is generated from installed npm packages and the Cargo dependency graph for the Windows target. It includes declared license identifiers and available license / notice text. Build and development dependencies are included conservatively; this is not a claim that every listed package is shipped in the installer.

Regenerate after changing either lockfile:

```powershell
npm ci
npm run notices
```

The installer includes `LICENSE` and `THIRD_PARTY_NOTICES.txt`. The generator fails if a dependency has no license declaration or no readable license / notice file, so missing material must be reviewed explicitly.

## Fonts

The application requests no remote UI fonts. Named interface fonts use locally installed fonts and system fallbacks; those system font files are not redistributed here. KaTeX's bundled mathematical fonts and their licenses are included with the dependency notices.
